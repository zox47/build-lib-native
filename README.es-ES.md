# Flet-Native 🚀

**Flet-Native** es una herramienta de vanguardia diseñada para simplificar la compilación de **paquetes de Python que no son puros**, los cuales pueden incluir componentes escritos en lenguajes como C, C++ o Rust. 🛠️

## Características Principales 🌟

- **Integración sencilla**: Compila paquetes populares como `firebase-admin` para iOS y Android con un esfuerzo mínimo.
- **Flujo de trabajo automatizado**: ¡Solo agrega tus bibliotecas requeridas al archivo requirements.txt y Flet-Native se encarga del resto! 🔄
- **Gestión automática de dependencias**: Flet-Native agrega automáticamente cualquier dependencia necesaria de las bibliotecas para evitar errores relacionados con bibliotecas faltantes. 📦
- **Sin trucos ni parches**: Dite adiós a complicados trabajos manuales; nuestra herramienta simplifica el proceso para usted. 🙌

## Uso 📦
1. Agrega los requisitos de tu paquete de Python no puro al archivo `requirements.txt`, y automáticamente agregará las dependencias de las bibliotecas.
   
2. Ejecuta el flujo de trabajo para automatizar el proceso de compilación.
   
3. Descarga la biblioteca como un archivo ZIP. 📥

### Ejemplo de `requirements.txt`:

```plaintext
firebase-admin
opencv-python
```
